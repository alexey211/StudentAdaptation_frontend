Иностранному студенту в первые недели нужно сделать много шагов: заселиться, оформить страховку, пройти медосмотр, подать документы. Платформа превращает этот путь в пошаговый чек-лист на родном для студента языке, показывает прогресс и собирает ответы на частые вопросы в одном месте.

Это фронтенд-часть проекта. Приложение работает целиком в браузере и не требует сервера, сборки и зависимостей.

## ✨ Возможности

- **Лендинг** с описанием платформы и макетом мобильного интерфейса.
- **Пошаговый чек-лист «Путь первокурсника».** Шаги выполняются строго по порядку: можно отметить следующий шаг или откатить последний. Это защищает от пропуска обязательных действий. После выполнения всех шагов запускается анимация с конфетти.
- **Доска прогресса** с общим процентом адаптации, который считается как доля выполненных шагов.
- **Справочник** с быстрыми ответами на частые вопросы.
- **5 языков интерфейса:** русский, английский, таджикский, французский, китайский. Переключаются на лету, сами шаги чек-листа переведены на все пять.
- **Режим администратора** без бэкенда:
  - редактор шагов чек-листа (добавление, правка, удаление, сброс к значениям по умолчанию);
  - конструктор вопросов для справочника;
  - загрузка логотипа, который отображается в центре экрана.
- **Адаптивная вёрстка** в современном «стеклянном» стиле (шрифт Inter, градиентный фон, анимации).

## 🛠 Технологии

| Область | Что использовано |
|---|---|
| Разметка и стили | HTML5, CSS3 (переменные, flex/grid, анимации) |
| Логика | Vanilla JavaScript, без фреймворков и сборщиков |
| Локализация | собственный словарь `data-i18n` на 5 языков |
| Хранение данных | `localStorage` браузера |
| Шрифты | Inter (Google Fonts) |

## 🚀 Запуск

Сборка не нужна. Есть два варианта:

**1. Открыть файл напрямую.** Откройте `index.html` в браузере и нажмите «Попробовать».

**2. Запустить локальный сервер:**

```bash
git clone https://github.com/<your-username>/StudentAdaptation_frontend.git
cd StudentAdaptation_frontend
python -m http.server 8000
```

После этого откройте http://localhost:8000.

## ⚙️ Как это работает

- **Данные и состояние.** Шаги чек-листа, прогресс, вопросы справочника и логотип хранятся в `localStorage` отдельными ключами. При первом запуске подставляются значения по умолчанию из `DEFAULT_TASKS` и `DEFAULT_GUIDE_ITEMS`.
- **Мультиязычность.** Каждый шаг хранит перевод на все языки (`ru`, `en`, `tg`, `fr`, `zh`). Статичные тексты интерфейса помечены атрибутом `data-i18n` и подставляются из словаря при смене языка.
- **Последовательный прогресс.** Прогресс хранится как номер последнего выполненного шага. Поэтому порядок нельзя нарушить, а процент выполнения вычисляется одной формулой.

## ⚠️ Ограничения текущей версии

Проект находится в разработке, это прототип:

- **Нет бэкенда.** Прогресс и правки администратора сохраняются только в браузере конкретного пользователя и не синхронизируются между устройствами.
- **Админ-режим не защищён по-настоящему.** Проверка пароля выполняется на клиенте, поэтому подходит только для демонстрации. Для продакшена нужна серверная авторизация.
- **Справочник пока наполнен заглушкой.** Механизм вопросов и ответов готов, контент добавляется через конструктор.
- **Напоминания (например, о продлении визы) показаны только на макете лендинга.** В приложении они ещё не реализованы.
